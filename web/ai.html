AI draft (opt-in demo)

This page calls the real LLM through POST /v1/tailor/ai. It only works when the server was started with a key. Sample data only.

Human review is required. The LLM only sees numbered blocks from the uploaded resume and the job, and every draft line must cite its sources like [S2]. The server re-checks this mechanically at approval and export: uncited lines, unknown citations, invented numbers or names, and lines whose wording leaves the cited sources all block approval. It is still not a fact check - a cited line can still twist a source's meaning, and qualifier inflation ("advanced Excel") can slip through. Review by eye.
